# GPT 服务设置研究：让普通人更轻松地接入 AI

> 研究日期：2026-11-17  
> 适用项目：GoldWord 2.0  
> 目标：让普通用户在不理解 OpenAI API、Base URL、模型名、Key 等概念的情况下，也能快速、安全地启用 GPT/大模型服务。

## 1. 当前 GoldWord 的 GPT 接入方式

当前实现已经比早期版本更友好：

- 默认基础地址：`https://api.caisheng.art/v1`
- 支持自定义 OpenAI 兼容源
- 支持主源 / 备用源切换
- 主源、备用源可独立配置模型和 Key
- 超时范围：3–120 秒
- 主源出现网络错误、限流或服务端错误时自动尝试备用源
- Android 正式包只允许 HTTPS
- API Key 保存在当前设备应用数据中，不硬编码、不提交 GitHub、不嵌入 APK

对应实现：

- `www/api-client.js`：统一的 OpenAI 兼容 `/chat/completions` 调用、Base URL 规范化、超时、主备切换
- `www/db.js`：GPT 设置读写、Base URL / API Key / model / timeout / fallback 配置
- `www/ui.js`：个人中心 GPT 服务设置界面

### 当前主要摩擦点

1. 用户仍需要手动填写 `Base URL`、`model`、`API Key`。
2. 国内平台的 Base URL、模型 ID 命名差异大，容易填错。
3. 免费额度、实名认证、有效期、限流规则分散在各平台官网，普通用户难以比较。
4. 很多平台需要先注册、实名、领额度，再创建 Key，步骤较多。
5. 错误提示主要来自 HTTP 原文，普通用户看不懂。
6. 没有“一键测试连接”“一键导入配置”“扫码导入”等降低门槛的入口。
7. 没有成本、剩余额度、调用次数的可视化。

### 2.1 免费额度的共同特点

- 大多数平台需要 **注册 + 实名认证**
- 免费额度通常有 **有效期**：30 天、90 天、180 天、1 年不等
- 很多平台默认 **不会自动扣费**，但部分平台需要手动开启“用尽即停”
- 免费额度用完后，服务会停止或开始计费
- 模型名会更新，旧模型可能 404
- 限流、并发、RPM/TPM 差异很大
- “免费”不等于“可商用”，很多平台明确仅限非商业试用

### 2.2 普通用户最容易踩的坑

1. **Base URL 多写或少写 `/v1`**，导致 `/v1/v1/chat/completions`
2. **模型名填错**，例如把展示名当模型 ID
3. **Key 复制不完整**，或保存后无法再查看
4. **免费额度到期后突然失败**
5. **额度用完后被扣费**
6. **平台限流导致请求失败**
7. **HTTP 错误信息看不懂**
8. **不知道哪个平台最适合自己的场景**

## 3. “扫码就能用”现状

搜索结果里，真正“扫码登录 / 微信扫码”的平台有，但 **扫码登录不等于扫码就能直接获得 API Key**。

### 已发现的扫码 / 微信登录入口

- **智谱 BigModel**：支持微信扫码登录
- **宇思 AI**：支持手机号 / 微信扫码注册
- **TokenAI Cloud**：支持微信扫码与手机号登录
- **晨涧云**：微信登录送 6 元优惠券，微信扫码绑定手机号
- **微信生态 AI 服务**：部分平台通过微信扫码获取 Coding Plan Token
- **上海 AI 实验室**：微信登录，每天签到领取额度
- **庖丁 AI**：微信扫码登录后自动生成 API Key
- **Codar / SpeedAI**：微信扫码登录 + 手机号验证，提供免费模型和积分

### 结论

目前 **没有一个主流平台做到“用户打开 GoldWord，扫码一次，就自动完成账号、Key、模型、Base URL 的全部配置”**。  
现有扫码能力主要用于：

- 登录账号
- 绑定手机号
- 领取优惠券
- 创建 API Key

因此，GoldWord 可以做的是 **“扫码导入配置”**：平台生成一个包含 Base URL、模型名、Key 或临时授权码的二维码，GoldWord 扫码后自动填入设置页。这比要求用户手动复制粘贴更友好。

## 4. 更好的导入与适配方案

### 4.1 一键预设模板

在 GPT 设置页增加“常用平台”下拉框，预填 Base URL 和推荐模型：

- 阿里云百炼
- 腾讯云 TokenHub
- 百度千帆
- 火山方舟
- 智谱 GLM
- 硅基流动
- 商汤 SenseNova
- DeepSeek 官方
- ModelScope
- 自定义

用户选择平台后，只需填写 API Key 和模型名。

### 4.2 模型目录自动拉取

调用所选 Base URL 的 `/v1/models`，自动列出可用模型，避免用户手填模型名。  
如果平台不支持 `/v1/models`，则回退到平台预设模型列表。

### 4.3 扫码导入配置

支持扫描二维码导入：

```json
{
  "provider": "zhipu",
  "baseUrl": "https://open.bigmodel.cn/api/paas/v4",
  "model": "glm-4.7-flash",
  "apiKey": "sk-xxx",
  "timeoutMs": 30000
}
```

也可以使用短链接或深链接：

```
goldword://gpt/import?provider=zhipu&baseUrl=...&model=...&key=...
```

安全要求：

- 二维码中的 Key 只在本地保存
- 不把 Key 上传到 GoldWord 服务器
- 导入前显示确认弹窗
- 支持“仅导入 Base URL 和模型，手动粘贴 Key”
- 支持一键清除 Key

### 4.4 连接测试与诊断

在保存前提供“测试连接”按钮：

- 检查 Base URL 是否可访问
- 检查 Key 是否有效
- 检查模型是否存在
- 返回可读错误：
  - Key 无效
  - 模型不存在
  - 网络不可达
  - 平台限流
  - 免费额度已用完

### 4.5 免费额度与成本提示

在设置页显示：

- 平台免费额度说明
- 有效期
- 是否需要实名
- 是否自动扣费
- 推荐模型
- 大致价格 / 免费模型

例如：

> 智谱：GLM-4.7-Flash 免费；新用户 2000 万 tokens 体验包；需要实名。  
> 腾讯云 TokenHub：新用户 20 模型 × 100 万 tokens，有效期 1 年。  
> 商汤：公测期免费，双积分池，每周 60 万积分。

### 4.6 多 Key / 多账户管理

当前已有主备切换。可以进一步支持：

- 多个 Provider 配置档案
- 一键切换“免费模式 / 付费模式 / 备用模式”
- 每个档案显示剩余额度、最近错误、成功率
- 自动故障切换与熔断

### 4.7 本地安全与隐私

- Key 永远只保存在当前设备
- 不上传 GoldWord 服务器
- 不写入日志
- 不嵌入 APK
- 提供“导出配置但不含 Key”的分享能力
- 提供“一键清除所有 GPT 设置”

### 4.8 普通用户引导

在 GPT 设置页增加“新手向导”：

1. 选择平台
2. 注册 / 实名 / 领免费额度
3. 创建 API Key
4. 填入或扫码导入
5. 测试连接
6. 保存并开始使用

并提供“推荐方案”：

- 最省钱：智谱 GLM-4.7-Flash / 商汤公测免费模型
- 最大免费额度：腾讯云 TokenHub
- 最多模型：硅基流动
- 最低成本旗舰：DeepSeek 官方
- 长上下文 Agent：MiniMax M3

## 5. 对 GoldWord 的具体改进建议

### 短期（1–2 周）

1. 增加平台预设模板，自动填 Base URL 和推荐模型。
2. 增加“测试连接”按钮。
3. 增加 `/v1/models` 自动拉取模型列表。
4. 优化错误提示，把 HTTP 错误翻译成用户可读信息。
5. 增加“新手向导”和免费平台说明。
6. 在设置页显示当前 Provider、模型、最近测试结果。

### 中期（2–4 周）

1. 支持二维码 / 深链接导入配置。
2. 支持多配置档案切换。
3. 增加用量、成本、剩余额度展示。
4. 增加自动故障切换和熔断。
5. 增加“仅导入非敏感配置”分享能力。

### 长期（1–2 月）

1. 建立 GoldWord 官方 Provider 目录，定期更新平台 Base URL、模型、免费额度。
2. 支持 OAuth / 扫码授权（如果平台开放）。
3. 支持 WebDAV / 云端同步加密配置（可选）。
4. 支持家庭 / 多设备配置同步（仅同步非敏感信息）。

## 6. 推荐的默认策略

建议 GoldWord 的 GPT 设置默认策略如下：

- 默认 Base URL：保留 `https://api.caisheng.art/v1` 作为兼容默认值
- 默认模型：不强制填写，要求用户选择或测试通过
- 默认超时：30 秒
- 默认主备：关闭，用户手动开启
- 默认 HTTPS：强制
- 默认 Key：空，不内置任何 Key
- 默认免费平台推荐：智谱 GLM-4.7-Flash 或 商汤 Token Plan

## 7. 安全边界

- 不内置任何 API Key
- 不把 Key 上传到 GoldWord 服务器
- 不在日志中输出 Key
- 不在 APK 中嵌入 Key
- 不在截图、分享、导出中泄露 Key
- 扫码导入必须二次确认
- 所有网络请求只访问用户配置的 Base URL

## 8. 结论

GoldWord 当前的 GPT 接入能力已经具备 OpenAI 兼容、主备切换、超时控制等基础能力。  
要让普通人更容易使用，关键不是再增加更多字段，而是：

1. **预设平台模板**
2. **自动拉取模型**
3. **扫码 / 一键导入**
4. **连接测试与可读错误**
5. **免费额度与成本提示**
6. **新手向导**

如果实现这些能力，用户从“注册平台”到“在 GoldWord 中成功调用 GPT”的步骤可以从现在的 8–10 步减少到 3–4 步，同时保持 Key 不泄露、不上传、不嵌入 APK 的安全边界。
